# UI/UX Task 1: User Research & Accessibility Audit

**Product Evaluated:** University Student Learning Management System (LMS) Portal  
**Standard:** WCAG 2.1 Level AA  

## Summary of Deliverables
- **Step 1:** Target undergraduate student persona & 5 structured interview questions
- **Step 2:** Synthesized feedback from 3 student participants & Nielsen Heuristic Evaluation
- **Step 3:** 5-area accessibility & usability audit (Navigation, Readability, Color Contrast, Forms, Mobile Usability)
- **Portfolio Upgrade:** P1–P5 impact vs. effort prioritized remediation plan
